# 🌐 ESP8266 Projects Hub

Welcome to my hardware and internet-of-things (IoT) web portfolio! This repository acts as the main landing page and central directory for hosting, organizing, and accessing my active ESP8266 web interfaces. 

By leveraging **GitHub Pages** alongside a single custom domain, this hub seamlessly routes to independent web applications hosted across separate repositories using clean subfolders.

## 🚀 Featured Web Projects

*   **[Onboard LED Blink](./esp8266-onboard-led-blink/)** 💡 – A web interface designed to interact with and control the onboard LED sequence of an ESP8266 microcontroller.
*   **[7-Segment Counter](./esp8266-7segment-counter/)** 🔢 – A web-based configuration module tracking live telemetry data and single-digit (3631AS) display cycling.

## 🛠️ How It Works (Multi-Repo Subfolders)

This project relies on GitHub's **User Site** structural layout:
1. This base repository is mapped directly to my custom domain root (`yourdomain.com`).
2. The independent project repositories are configured for GitHub Pages with their *Custom Domain fields left blank*.
3. GitHub automatically serves those standalone builds as relative subfolders (e.g., `://yourdomain.com`).

## 💻 Tech Stack
*   **HTML5** – Semantics and structure.
*   **CSS3** – Minimalist dark-aesthetic layout, glassmorphism UI card effects, and hover transitions.
*   **JavaScript (ES6)** – Dynamic UI feedback and event handlers.
